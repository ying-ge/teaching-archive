# 教师教学档案目录结构 · Teaching Archive

依据《本科教学质量标准（2025 年）·第一部分 教学过程》，把其中的**可核查要求**逐条抽出，
转成一套**每位教师、每门课程、每个学期完全相同**的教学目录结构——既是归档位置，也是工作提示与引导。

> 由 [Wisp Science](https://github.com/wisp-science/wisp-science)（开源、本地优先的桌面 AI agent）读取规定 PDF 并直接写入文件树完成。复现方法见 [docs/复现提示词.md](docs/复现提示词.md)。

## 这个仓库解决什么

规定条文通常写成连续的文章，教师很难据此判断"该准备什么、放哪里、什么时候交"。本仓库做三件事：

1. **规则提取**：`教师教学档案/教学规程速查.md` 把硬性要求（时限、量化指标、红线）逐条列出并标注页码。
2. **目录映射**：目录编号与规定章节一一对应（`01_课程准备`…`06_总结与改进`），看到文件夹就知道对应哪条要求、该放什么。
3. **提示与引导**：每个文件夹的 `说明.md` 写明「规定怎么说 / 这里放什么 / 时限与红线」；课程根 `README.md` 是学期工作时间轴；`00_材料总清点表.md` 把 114 项材料汇总成可勾选清单。

## 目录快照

```
教师教学档案/
├── README.md              # 总说明：目录↔条款对照、三层结构
├── 教学规程速查.md          # 逐条规则清单（含时限与页码）
├── _模板/                  # 空白模板：一名教师 · 一门课程 · 一个学期
│   ├── 00_材料总清点表.md     # 总入口：114 个条目
│   ├── README.md           # 学期工作时间轴（12 个节点）+ 自查表
│   └── 01_课程准备 … 06_总结与改进/
│       ├── 说明.md          # 规定怎么说 / 这里放什么 / 时限与红线
│       └── *模板.md         # 可复制填写的表单（16 张）
└── ...                     # 生成后按 教师姓名/学年学期_课程名称/ 展开
```

按教师名单批量生成（先在脚本顶部填 `教师名单`，不填则只提示不改动任何文件）：

```bash
python3 生成教师档案.py
```

表单统一使用三个标记：**【必填】** 缺项即不合格；**⚠禁止编造** 只许照抄来源；**【选填】**。

完整对照表（含页码）见 [教师教学档案/教学规程速查.md](教师教学档案/教学规程速查.md)。
