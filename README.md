# 教师教学档案目录结构 · Teaching Archive

依据《本科教学质量标准（2025 年）·第一部分 教学过程》，把其中的**可核查要求**逐条抽出，
转成一套**每位教师、每门课程、每个学期完全相同**的教学目录结构——既是归档位置，也是工作提示与引导。

## 这个仓库解决什么

规定条文通常写成连续的文章，教师很难据此判断"该准备什么、放哪里、什么时候交"。
本仓库做三件事：

1. **规则提取**：`教师教学档案/教学规程速查.md` 把规定中的硬性要求（时限、量化指标、红线）逐条列出并标注页码，便于回查原文。
2. **目录映射**：目录编号与规定章节一一对应（`01_课程准备`…`06_总结与改进`），看到文件夹就知道对应哪条要求，以及该放什么。
3. **提示与引导**：每个文件夹的 `说明.md` 写明「规定怎么说 / 这里放什么 / 时限与红线」；课程根 `README.md` 是学期工作时间轴；
   `00_材料总清点表.md` 把 114 项材料汇总成一张可勾选清单。

## 快照（超链接，可用 [查看](教师教学档案/README.md)）

```
教师教学档案/
├── ReadME.md              # 总说明：目录↔条款对照、填写标记、三层结构
├── 教学规程速查.md          # 逐条规则清单（含时限与页码）+ 硬性时限一览表
├── _模板/                  # 空白模板：一名教师 · 一门课程 · 一个学期
│   ├── 00_材料总清点表.md   # 总入口：114 个条目（时限、必填性、不适用标记）
│   ├── README.md           # 学期工作时间轴（12 个节点）+ 自查表 + 命名约定
│   └── 01_课程准备 … 06_总结与改进/
│       ├── 说明.md          # 规定怎么说 / 这里放什么 / 时限与红线
│       └── *模板.md         # 可直接复制填写的表单（共 16 张）
└── ...                     # 生成后按 教师姓名/学年学期_课程名称/ 展开
```

`生成教师档案.py` 按教师名单批量复制模板，并自动替换 `{{教师姓名}}`、`{{课程名称}}`、`{{学年学期}}`：

```bash
python3 生成教师档案.py
```

（先在脚本顶部填写 `教师名单`；不填则只提示如何填写，不会改动任何文件。）

## 目录与条款对照

| 目录 | 对应规定条款 |
|---|---|
| `01_课程准备/01…09` | 备课、教材、教学进度、教案、讲稿、课件与教具、集体备课、试讲与学习性听课、说课 |
| `02_课程教学/01…02` | 理论教学、实验教学 |
| `03_实践教学/01…03` | 临床见习、临床实习、临床技能培训 |
| `04_教学手段/01` | 多媒体教学 |
| `05_课程评价/01…03` | 形成性评价、考试考核、试卷与存档 |
| `06_总结与改进` | 阶段性教学总结、课程小结、持续改进台账 |

完整对照表（含页码）见 [教师教学档案/教学规程速查.md](教师教学档案/教学规程速查.md)。

## 填写标记约定

| 标记 | 含义 |
|---|---|
| **【必填】** | 规定要求记载的项，缺项即材料不合格 |
| **⚠禁止编造** | 只许照抄来源（大纲、教材版权页、课表、成绩单、签到表等），不得估填，也不得由 AI 生成 |
| **【选填】** | 视课程实际情况填写 |

## 适配到其他学校

规则条文与页码朝向本仓库依据的那份文件；换学校时按三步改：

1. 用本方文件替换 `教学规程速查.md` 的条款与页码；
2. 核对 `_模板/*/说明.md` 中的「规定怎么说」与时限；
3. 核对 `00_材料总清点表.md` 的 114 条与其"规定依据"列。

目录骨架、标记体系与生成脚本无需改动。

## 说明

- 仓库内**不含任何真实教学材料**（学生成绩、试卷、病例、教师个人信息均不入库），仅提供空白模板。
- 涉及学生或患者个人信息的材料，请勿提交到任何代码托管平台。
- 参考资料：GitHub 同类项目调研见 [GitHub同类项目调研.md](GitHub同类项目调研.md)。
