# 教师教学档案目录结构 · Teaching Archive

依据《本科教学质量标准（2025 年）·第一部分 教学过程》，把其中的**可核查要求**逐条抽出，
转成一套**每位教师、每门课程、每个学期完全相同**的教学目录结构——既是归档位置，也是工作提示与引导。

> **生成工具**：本仓库由 [Wisp Science](https://github.com/wisp-science/wisp-science)（开源、本地优先的桌面 AI agent）读取规定 PDF 并直接写入文件树完成——不是对话式 AI 输出后手工誊抄。复现方法见 [用你自己学校的规定文档生成](#用你自己学校的规定文档生成)。

## 这个仓库解决什么

规定条文通常写成连续的文章，教师很难据此判断"该准备什么、放哪里、什么时候交"。
本仓库做三件事：

1. **规则提取**：`教师教学档案/教学规程速查.md` 把规定中的硬性要求（时限、量化指标、红线）逐条列出并标注页码，便于回查原文。
2. **目录映射**：目录编号与规定章节一一对应（`01_课程准备`…`06_总结与改进`），看到文件夹就知道对应哪条要求，以及该放什么。
3. **提示与引导**：每个文件夹的 `说明.md` 写明「规定怎么说 / 这里放什么 / 时限与红线」；课程根 `README.md` 是学期工作时间轴；
   `00_材料总清点表.md` 把 114 项材料汇总成一张可勾选清单。

> 想用**你们学校自己的**规定文档重做一套？见 [用你自己学校的规定文档生成](#用你自己学校的规定文档生成)——含原始提示词与可直接复制的通用模板。

## 目录快照

```
教师教学档案/
├── README.md              # 总说明：目录↔条款对照、填写标记、三层结构
├── 教学规程速查.md          # 逐条规则清单（含时限与页码）+ 硬性时限一览表
├── _模板/                  # 空白模板：一名教师 · 一门课程 · 一个学期
│   ├── 00_材料总清点表.md     # 总入口：114 个条目（时限、必填性、不适用标记）
│   ├── README.md           # 学期工作时间轴（12 个节点）+ 自查表 + 命名约定
│   └── 01_课程准备 … 06_总结与改进/
│       ├── 说明.md          # 规定怎么说 / 这里放什么 / 时限与红线
│       └── *模板.md         # 可直接复制填写的表单（共 16 张）
└── ...                     # 生成后按 教师姓名/学年学期_课程名称/ 展开
```

`生成教师档案.py` 按教师名单批量复制模板，并自动替换 `{{教师姓名}}`、`{{课程名称}}`、`{{学年学期}}`：

```bash
python3 生成教师档案.py
```

（先在脚本顶部填写 `教师名单`；不填则只提示如何填写，不会改动任何文件。）

| 目录 | 对应规定条款 |

| `05_课程评价/01…03` | 形成性评价、考试考核、试卷与存档 |
| `06_总结与改进` | 阶段性教学总结、课程小结、持续改进台账 |

完整对照表（含页码）见 [教师教学档案/教学规程速查.md](教师教学档案/教学规程速查.md)。

## 填写标记约定

| 标记 | 含义 |
|---|---|
| **【必填】** | 规定要求记载的项，缺项即材料不合格 |
| **⚠禁止编造** | 只许照抄来源（大纲、教材版权页、课表、成绩单、签到表等），不得估填，也不得由 AI 生成 |
| **【选填】** | 视课程实际情况填写 |

## 用你自己学校的规定文档生成

本仓库是**用 Wisp Science 这个 AI agent 做出来的**，不是把文档丢给对话式 AI 聊天窗口就能得到的产物。

普通的对话式 AI 只能"读文档 → 在聊天框里吐一段文字"，它**拿不到你的磁盘**：没法把 37 个文件、24 个文件夹真的建出来、没法把每张表单写成文件、没法解析 PDF 原文页码、也没法写脚本按教师名单批量生成。而这份目录结构是一整套**落地的文件树**，必须由具备本地文件读写与执行能力的 agent 来完成。

> **Wisp Science** —— 开源、本地优先的桌面 AI 科研工作台，可读写本地文件、解析 PDF、执行 Python／R／Shell、调用浏览器检索。
> 仓库：<https://github.com/wisp-science/wisp-science>

### 实际用到的能力（也就是普通 AI 做不到的部分）

| 环节 | 需要的能力 | 对话式 AI |
|---|---|---|
| 读 `教学过程.pdf` 全文并逐页核对 | PDF 解析（24 页文本层提取） | ✗ 只能靠你把文字粘进去，粘不全就漏条款 |
| 建 37 个文件 / 24 个文件夹（含 18 个编号子目录） | 本地文件系统读写 | ✗ 只能给你一段"你自己照着建"的清单 |
| 生成 19 份 `说明.md`、16 张表单 | 批量写文件 | ✗ 手工复制粘贴 |
| 写 `生成教师档案.py` 并实际跑通验证 | 执行脚本、检查产物 | ✗ 无法运行，无法验证 |
| 查 GitHub 有无同类项目 | 浏览器实时检索 | ✗ 只能凭记忆，会给出不存在的仓库 |
| 分步推进并自查（提取→模板→脚本→核对） | 多步计划与文件核对 | ✗ 单轮输出，无中间校验 |

### 原始提示词

> 教学过程.pdf规定了进行本科生教学的规定，提取这些规则，为每位老师建立一套统一的教学目录结构，以满足这些规定，同时起到提示、引导作用

这条提示词本身很短；能落地，靠的是 agent 侧的读文件、写文件、跑脚本、核对产物这几步能力。

### 通用模板（把方括号换成你自己的情况，交给同类 agent 执行）

> 附件《[本校文件名]》规定了本科教学的各项要求。请完成三件事：
>
> 1. **提取规则**：把其中可核查的硬性要求（时限、次数、比例、量化指标、禁止性条款）逐条列出，并标注原文页码，便于回查。
> 2. **建立统一目录结构**：为每位教师、每门课程、每个学期设计**完全相同**的一套文件夹；文件夹编号与规定章节**一一对应**，看到目录就知道对应哪条要求、该放什么材料。**请直接建出这套目录与文件，不要只给清单。**
> 3. **落实提示与引导**：每个文件夹内放一份说明，固定三段式——「规定怎么说（含页码）／这里放什么／时限与红线」；提供可直接复制填写的表单模板；课程根目录给出**学期工作时间轴**与自查清单。
>
> 约束：
>
> - 不改动、不替我方的文件内容，只做条款摘录并标注页码；
> - 表单中不得出现我方材料里没有的数据（成绩、比例、人数、姓名、教材版本一律照抄来源）；
> - 最后附两份汇总：**硬性时限与量化要求一览表**、**材料与存档清单**（每种材料对应存放目录）。

### 可选的追加提示词

| 想要的效果 | 追加的提示词 |
|---|---|
| 总清点表 | 把各目录"这里放什么"的全部条目汇总成一张可勾选清单，含时限节点与依据页码 |
| 必填／禁编标注 | 给每张表单标注【必填】项，并注明本表"禁止编造"的具体项（只许照抄来源，不得估填或由 AI 生成） |
| 批量生成 | 写一个脚本，按"教师名单＋课程"批量复制模板，并替换其中的姓名／课程／学期占位符 |
| 精简 | 说明段太多，只保留承载区分信息的标记，其余删掉 |
| 查同类项目 | 查一下 GitHub 上有没有类似目的的开源项目，说明差异（参见 [GitHub同类项目调研.md](GitHub同类项目调研.md)） |

### 换到你的学校后要改的三处

目录骨架、标记体系与生成脚本都不用改，只需替换规则来源：

1. 用本方文件替换 `教学规程速查.md` 的条款与页码；
2. 核对 `_模板/*/说明.md` 中的「规定怎么说」与时限、红线；
3. 核对 `00_材料总清点表.md` 的 114 条条目及其"规定依据"列（条目数会随本方文件多少而变）。

> 提示：把本方文件的**页数**先告诉 agent（例如"共 24 页"），并要求它核对全文后再提取规则 —— 本仓库的原始文件就出现过"书签里有、正文里没有"的残留条目，需要显式排除。文件树建好后，让它**逐项核对产物**（文件数、占位符是否残留、目录是否与条款对齐），这一步是对话式 AI 无法完成的。
