# 教师教学档案

本目录依据《本科教学质量标准（2025 年）·第一部分 教学过程》建立**统一的教学目录结构**：
每位教师、每门课程、每个学期使用**完全相同**的一套文件夹；文件夹的编号与内容，
与规定条款一一对应，既是**归档位置**，也是**工作提示**。

## 三层结构

```
教师教学档案/
├── 教学规程速查.md          ← 从规定中逐条抽取的规则清单（含时限与页码）
├── _模板/                    ← 空白模板：一名教师 · 一门课程 · 一个学期
│   ├── 00_材料总清点表.md     ← 总入口：114 个条目一次清点（含时限、必填性、不适用标记）
│   ├── README.md             ← 学期工作时间轴 + 自查表 + 命名约定
│   └── 01…06/                ← 各环节：说明.md（规定/放什么/红线）+ 可填表单
├── 生成教师档案.py            ← 按教师名单批量生成（自动复制模板并替换姓名/课程）
└── <教师姓名>/
    └── <学年学期>_<课程名称>/ ← 由模板复制而来，结构与 _模板 完全一致
```

## 怎么用

1. **一位教师**：运行 `python3 生成教师档案.py`（先在文件顶部的"教师名单"里填姓名与课程）。
   程序会为每人每门课复制一套目录，并把 `{{教师姓名}}`、`{{课程名称}}`、`{{学年学期}}` 自动替换。
   手工复制 `_模板` 也可以，效果相同。
2. **一个学期**：先读课程目录里的 `README.md`（学期工作时间轴），照时间轴推进；
   每个环节动手前，打开对应文件夹的 `说明.md`。
3. **每个文件夹**：`说明.md` 写清"规定怎么说 / 这里放什么 / 时限与红线"；
   带"模板"字样的文件可直接复制填写、改名归档。
4. **归档**：材料就地归档，文件名建议 `日期_内容_版本`（如 `20250310_第三章教案_v2.docx`）。
   凡规定要求**纸质存档**的（教案、集体备课形成的基本教案与课件、试卷），电子件仍放本目录，纸质件按教研室要求另行存放。
