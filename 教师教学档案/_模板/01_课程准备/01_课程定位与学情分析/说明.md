# 说明 · 课程定位与学情分析

**规定依据**：一、课程准备 → 备课（个人备课第 1～5 条）〔p1〕

## 规定怎么说

1. 任课教师要了解本门课程在整个专业教学计划中的地位和任务，研究与相关学科课程、先修后续课程的联系。
2. 认真学习和领会学校的各项规章制度、教学相关文件。
3. 掌握本门课程的教学大纲和教学基本要求，分清主次、逻辑结构，准确把握"三基""三性""三点"。
4. 做好**学情分析**，调查学生学习基础、知识结构和先修课程的学习情况，深入研究学生的知识现状，因材施教。
5. 钻研教材的同时广泛收集阅读参考资料，了解学科最新进展。

## 这里放什么

- [ ] 课程定位说明（课程在专业培养方案中的地位、任务、学分学时）
- [ ] 先修课程 / 后续课程关系图或清单
- [ ] 本课程"三基／三性／三点"梳理（基础理论·基本知识·基本技能；科学性·系统性·实践性；重点·难点·疑点）
- [ ] 学情分析表（用本目录 `学情分析表.md`）
- [ ] 参考资料与学科进展摘录清单

## 提示

- 学情分析不是一次性作业：每轮授课前，用上一轮的成绩、作业、测验数据更新它。
- 学情分析结论要能落到教学上（分层要求、案例选取、作业难度），才符合"因材施教"。
