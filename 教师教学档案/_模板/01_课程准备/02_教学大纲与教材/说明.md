# 说明 · 教学大纲与教材

**规定依据**：一、课程准备 → 备课（第 3 条）、教材〔p1、p5–6〕

## 规定怎么说

**教学大纲**：掌握本门课程的教学大纲和教学基本要求，分清主次、逻辑结构。

**教材选用（关键硬性要求）**

- 凡选必审；质量第一（优先国家规划教材及省部级以上获奖教材）；适宜教学；公平公正；统一使用（马工程重点教材对应课程必须选用马工程教材）。
- 不得选用政治立场和价值导向有问题、内容陈旧、低水平重复、简单拼凑的教材。
- 必修课和**学时 ≥32 学时**的选修课原则上选用公开出版的国家规划教材；自编教材未经学校审批不得列入选用计划。
- 同一教学大纲的课程原则上选用同一版本教材；更换版本须报教材建设办公室批准并严格控制。
- **选用程序**：每学期编制一次；一般在前一学期**第 10～12 教学周**制定下一学期教材选用计划；教研室填报《教材使用计划表》→ 教学单位教材建设分委会审核 → 学校教材建设委员会办公室审核备案。
- 要求更换新版本教材的课程，教研室必须填写并提供**新教材样书或编写大纲**，按程序审批后方可更换。
- **红线**：授课中另行安排计划外教材，一经查实对责任人**按教学事故处理**。使用外国教材必须是原版或已授权的国内版并报主管部门批准。

## 正式模板（以学校现行版本为准）

本目录只提供**提示清单**，正式文本必须使用学校模板：

- 教学大纲：`教学大纲参考模板（2024年）241105.docx`
- 参考样例：`教学大纲-生物化学-基础医学-64学时.doc`
- 完整规定：校级《本科教学质量标准》全文（第二部分·五 教学规范 → 本科教学大纲〔p63〕、本科实验教学大纲〔p64〕）

> 用户自建目录中上述文件位于 `0规定/`、`1参考资料/`。换学校时替换为各自版本；这些是校内文件，**不要提交到公开仓库**。

**大纲撰写要点（来自官方模板）**

- 认知层级**统一用"记忆／理解／应用"**，不再使用"掌握、熟悉、了解、自学"
- 章节结构：目的与要求（知识／能力／思政三项目标）→ 教学内容 → 【重点】【难点】【考核要点】→ 思考题
- **每章须填"考核分值"**（可写范围如 3-7 分），理论课与实验/见习分表列出，最后填合计——该分值须与命题时的双向细目表一致
- 考核与评价：终结性＋过程性相结合（选修课可写"过程性评价为主"），**至少 3 种**方式并注明各占比例
- 保留原模板的字体、字号、加粗、行间距；正式上报版删除红字注解

- **关键时间点**：上一学期第 10～12 教学周 → 提交教材选用计划（逾期即影响下学期开课用书）。
- **不要**在授课中擅自使用计划外教材。
