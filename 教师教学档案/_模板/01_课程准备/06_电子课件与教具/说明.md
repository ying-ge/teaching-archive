# 说明 · 电子课件与教具

**规定依据**：一、课程准备 → 备课（个人备课第 12 条）〔p2〕；理论教学保障〔p7〕；多媒体教学质量标准〔p19–20〕

## 规定怎么说

- 在上课前准备好**图表、教具、电子课件、作业习题**等，必要时要进行预讲和演练。
- 上课时应携带合格的**教案、讲稿、电子课件、教具以及教材**等必要材料。
- 多媒体课件须符合"教学标准、技术标准、文档资料完整、特色部分"四方面质量标准（详见 `04_教学手段/01_多媒体课件`）。

## 这里放什么

- [ ] 电子课件（按章命名，注明版本）
- [ ] 图表、图片、动画、音视频、虚拟仿真资源
- [ ] 教具清单与借用记录
- [ ] 作业习题与答案
- [ ] 预讲／演练记录（必要时）

## 提示

- 课件版本变更要在文件名或版本表中体现，避免课堂上误用旧版。
- 若课件需要对外交流、评比或上网，请把**功能简介与使用说明书**一并放到 `04_教学手段/01_多媒体课件`。
- 一旦课件中使用了他人受版权保护的图片，请注明来源。

## 自查

- [ ] 课件与教案、讲稿的知识点顺序一致
- [ ] 课件中重点、难点有明确呈现方式（动画、对比、框图等）
- [ ] 上课前已在授课教室试运行过课件（多媒体设备操作培训每学期开学前 2 次）
