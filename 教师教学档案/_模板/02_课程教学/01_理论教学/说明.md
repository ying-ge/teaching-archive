# 说明 · 理论教学

**规定依据**：二、课程教学 → 理论教学〔p6–8〕

## 规定怎么说

**质量保障（可核查动作）**

1. 教师应在规定的上课时间**之前**进入教室，熟悉环境，调配教具与教学辅助设备等，将手机等通讯设备**关闭**。
2. 教师上课前认真备课，上课时应携带**合格的教案、讲稿、电子课件、教具以及教材**等必要的材料。
3. 教师准时上课，**不提前下课，也不延长时间**。
4. 教师认真组织课堂教学，保持教学秩序良好。
5. 教研室合理安排任课教师，制定合理、正确的授课时间日程，便于教师参考。
6. 建立**授课提醒制度**。

**评价标准（5 个维度）**

| 维度 | 要点 |
|---|---|
| 教学态度 | 敬业精神、态度端正、仪表得体；备课准备充分、教案规范、遵守时间；为人师表、教书育人、关心学生 |
| 教学能力 | 精通专业内容、了解相关学科知识；语言准确精练生动、深入浅出；讲授有系统性、重点突出、循序渐进；思维敏捷、能准确快速回答学生提问；合理运用课堂时间 |
| 教学内容 | 基本理论概念讲解清楚准确；重点突出、深度广度适宜；贯彻理论联系实际；**按既定教案进行**；保证科学性、禁止"照本宣科"；注意相关学科联系；注重思政元素，知识传授与价值引领相统一 |
| 教学方法 | 启发式、案例式、以问题为中心的研究性学习；合理运用现代化信息技术及各种教学手段；板书清晰、条理清楚、重点突出 |
| 教学效果 | 及时总结归纳；激发学习兴趣、活跃思维；学生反映好、达到教学互动；因材施教、提高综合素质 |

## 提示

- 教案、讲稿、课件、教具、教材**五件齐备**再进教室，这是每次课的"进门检查"。
- 课堂"照本宣科"是明文禁止项，教学方法维度要能体现启发式/案例式/PBL。
- 互动、提问、随堂测验的记录同时是 `05_课程评价/01_形成性评价` 的物化材料，**一次记录两处可用**。

## 自查

- [ ] 每次课提前到教室、关闭手机
- [ ] 不提前下课、不拖堂
- [ ] 教学内容与既定教案一致，偏离处已记录原因
