# 说明 · 实验教学

**规定依据**：二、课程教学 → 实验教学〔p8–10〕

## 规定怎么说

**准备**

- 实验课必须有**实验教学大纲**（组织实验教学的指导性文件），明确实验课在教学计划中的地位与作用。
- 教研室根据教务处下达的教学任务安排实验指导教师，制定**实验教学计划、实验教学日历**。
- 实验指导教师课前认真备课，掌握课程教学大纲和实验教学大纲，熟悉实验指导、讲义全部内容，熟练掌握实验技能操作，了解仪器设备基本原理，编写**实验指导提纲**，做好仪器、设备、试剂、动物等准备。
- **预实验**：新开设的实验内容，教研室必须在**开课之前的一个学期**完成预实验；若是综合性、设计性实验，必须邀请相关专家**论证并做好记录**；非新开设的实验内容应在**实验教学一周以前**完成预实验。
- 针对不同专业、不同层次对实验项目、内容进行删减重组，体现因需施教。
- 教研室定期召开实验教学研讨会，大力开展综合性、设计性实验并不断扩大比例。
- 建立健全并不断完善实验室制度，建立**实验室档案**。

**开展**

- 重点讲授每项实验的目的、内容、步骤、要求；以学生独立操作为主，教师随时注意操作情况，发现问题或故障及时纠正解决。
- 严格遵守上下课时间与课堂纪律，对学生**严格考勤并记录**。
- 课前组织学生检查仪器设备、试剂等是否齐全；实验完成后清点用品、做好卫生清扫与基本保养维护。
- 任课教师课后**认真批改实验报告**，实验报告成绩可作为实验成绩的一部分。
- 实验课成绩应占该课程总成绩的一定比例；**实验课考核及格者，方可参加该门课程理论考试**。
- 完善实验室开放制度，课余时间向学生有计划地开放。

## 这里放什么

- [ ] 实验教学大纲、实验教学计划、实验教学日历
- [ ] 实验指导提纲、实验讲义
- [ ] **预实验记录**（用 `预实验记录表.md`）；综合性、设计性实验的专家论证记录
- [ ] 实验安排表、分组名单、考勤记录
- [ ] 实验报告及批改记录（成绩可计入实验总评）
- [ ] 实验课考核成绩、及格名单（理论考试准入依据）
- [ ] 实验室制度、实验室档案、开放记录
- [ ] 实验教学研讨会记录、实验项目更新记录

## 时限红线

| 实验类型 | 预实验完成时限 |
|---|---|
| 新开设实验 | **开课之前的一个学期**（综合性、设计性实验须专家论证并记录） |
| 非新开设实验 | **实验教学一周以前** |

## 自查

- [ ] 实验课考核及格名单已单独留存（不及格者不得参加理论考试）
- [ ] 每次课的仪器、试剂、动物准备清单已留痕
