# 说明 · 临床实习

**规定依据**：三、实践教学 → 临床实习〔p11–17〕（由 10 个方面标准组成）

## 规定怎么说（按可执行要点摘要）

**实习文件标准**：实习计划、实习大纲、实习手册、实习考核表等教学文件完备、执行严格，由教务处组织临床教学专家编写并定期修订。
- 实习计划应做到实习时间、要求明确，进度安排合理，方便实习轮转；**教务处根据教学进程提前两个月下达**各专业实习计划任务。
- 实习大纲内容应包括专业培养目标、培养要求、实习目的与要求、实习时间安排、实习内容、实习基本技能、专题讲座、教学组织与方法等；格式规范，认知分级明确，与教学大纲协调一致并定期修订。
- 实习手册及实习考核表要求内容全面、针对性强、便于记录和实际操作；考核内容重点在基本能力水平和平日学习表现，含基本素质考核与专业能力考核。

**教学基地标准**：具备相应教学环境和条件，建有智慧化教室、示教室，能远程教学；师资实践经验丰富；有足够实习病种或教学示例；有完善的管理规章制度和教学管理组织机构。

**实习准备标准**：学校、二级学院、教学基地、带教教师、学生各层面准备到位；二级学院实习前开展**实习动员**（安全培训、规章制度宣讲、学习方法、注意问题、医院管理流程、医德培养、业务培训、思想动员）；教学基地在学生进入基地后组织**入院前培训**。

**实习管理标准**：机构设置合理、职责明确、制度健全、执行严格、记录完整；教学文件与档案齐全、归类有序；严格按照实习计划和实习轮转表组织安排，完成学生全部实习内容。
- 每个科室设置 **2 张以上教学专用床**用于调节病种；每名实习学生负责管理 **6～8 张病床**为宜。
- 科室主任总体负责实习教学；指导教师原则上由**高年资住院医师及以上**者担任，**不允许进修医师担任**；每名指导教师负责指导 **1～2 名学生**。

**实习带教标准**：贯彻"三基""三严"，培养临床思维与临床综合能力；专业知识扎实、操作规范熟练；言传身教、因材施教，及时纠正错误知识与不当操作并示范标准；教学方法手段合理得当；高度责任心，业务与品德培养并重。

**教学查房标准**：执行《教学查房规范（试行）》；**教研室教学查房每周至少安排一次，要有计划、有实施、有记录和总结**；各级带教教师熟悉并严格执行规范；紧密结合临床，重点培养临床思维；目的明确、准备充分、过程有序完整、效果好。

**专题讲座标准**：内容紧密结合临床实践，适当充实前沿理论和学科发展内容；主讲人认真准备，重点突出、概念清楚、定义准确；注意启发式教育，教与学互动效果好，合理利用多媒体等现代化教学手段；各教研室制定学期专题讲座计划，安排临床、教学经验丰富的高年资教师承担；**专题讲座每 1～2 周安排一次，时间、题目、主讲人一旦确定不得随意更改**。

**实习考核标准**
- 考核成绩按百分制记分。方式一：平时考核 70 分＋出科理论考试 30 分；方式二：平时考核 40 分＋出科技能考核 30 分＋出科理论考试 30 分。
- 平时考核由带教教师评定、教研室审定，内容含劳动纪律、服务态度、遵守制度、工作表现、文书书写、体格检查、基本操作等。
- 出科技能考核以**面试形式**（床前或临床技能训练设备、模拟病人等）考核本科室基本工作技能和临床实践知识。
- 出科理论考试以**笔答形式**考核本科室教学内容，重点考核理论联系实际的应用能力和临床思维。
- 试卷命题和阅卷参照《学生学习成绩考核管理规定》；**各学院组织教研室统一命题，每轮出科考试前保密下发各教学基地，统一时间组织出科考试**。
- 成绩用**蓝、黑墨水**填写，不得污损及涂改；成绩评定表、实习成绩表须**考评教师及教研室主任签字**；上报二级学院及学校的成绩登记单须**教学基地教学管理部门盖章**；成绩评定客观、严格、公正；二级学院与教学基地做规范的考试总结。

**医疗文书书写标准**：带教教师必须对学生的各种医疗文书进行**审查、修改和补充并签名**；**每页修改超过两处必须重新抄写**；病史采集真实完整系统；使用规定颜色笔、字迹清楚规整；规范使用医学术语，不得自行杜撰简化或缩写。

**二级学院对教学基地教学查房（教学指导）标准**：每学期**有计划、有实施、有记录、有总结**；以示范教学、指导基地教师和学生为主要目的；学院、基地、科室、教师、学生充分准备，提前确定病例、用品、场所；**查房教师要求职称为副教授以上**，具有丰富临床和教学经验。

## 频次与量化红线

| 事项 | 要求 |
|---|---|
| 实习计划下达 | 教务处**提前两个月** |
| 教学专用床 | 每科室 ≥2 张 |
| 学生分管病床 | 6～8 张/人 |
| 指导教师 | 高年资住院医师及以上；进修医师不得担任 |
| 指导人数 | 1～2 名学生/教师 |
| 教学查房 | 每周 ≥1 次，有计划、实施、记录、总结 |
| 专题讲座 | 每 1～2 周 1 次，确定后不得随意更改 |
| 二级学院教学查房 | 每学期有计划、实施、记录、总结；查房教师副教授以上 |
