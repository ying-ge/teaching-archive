# 说明 · 考试与考核

**规定依据**：五、课程评价 → 考试、考核〔p22–23〕

## 规定怎么说

**（一）命题的基本要求**

1. 每门课程应有**考试大纲或考核要求**，内容包括：考试的目的和性质；考试的内容和范围；考试的方法和形式（包括题型、题目数量、各部分内容所占分数比例、答卷方式等）。
2. 考试课和须闭卷考核的考查课均须命出**难易度等同的 A、B、C 三套试卷**，同时都要做出**标准答案与评分标准**；由教务处随机抽取一套用于正常考试，另两套封存备补考考试使用。**主客观试题比例约为 6:4**，**难、中、易比例需要控制在 1:3:1**。双语教学课程要求用英文命题所占比例**不低于 50%**。

**（二）命题质量**

1. 试题以教学大纲和教材为依据，题型多样化；重点考核基础知识和基本技能的掌握程度以及综合运用知识、分析解决实际问题的能力；有利于引导学生建立科学思维和启发创新意识；科学原理不得有误，指示性语言清晰简练。
2. 试卷必须采用**统一的试卷模板**，格式符合统一要求，打印清楚、印刷规范，图表文字无错误。
3. 原则上所有考试课科目，要求作出**命题计划**，从题库命题、组卷。
4. 标准答案和评分标准科学、**采分点明确**，并能严格执行。
5. **成绩呈正态分布**。

**（三）考核形式**

1. 各专业的主干课、考试课由教务处统一安排。
2. 考查课、选修课的成绩考核由各二级学院及教研室针对课程特点，根据学生平时听课、实验、实习、讨论、完成作业以及平时测验的结果综合评定；**但不能降低标准，要保存好相关材料以备检查**。

**（四）阅卷质量**

1. 对考试课实行**网上评卷**。
2. 严格按照评分标准阅卷，各题应得分、试卷总分无错误。
3. 试卷需**多人流水作业**判题，同时组织好试卷的复查工作。
4. 卷面批阅形式统一，规范、整洁、美观；必须认真填写试卷封面上的各项内容，**每小题需要有得分标记**；有实验（见习）、期中考试占分值的课程，其理论课程可按实际所占比率出题或折算分值。
5. 试卷批阅如有改动**必须有阅卷人签字**；成绩如有疏漏需改动**必须填写成绩变更审批表**后方可生效。
6. 考试总结规范，分析科学、客观，并能反馈、指导教学。

## 这里放什么

- [ ] 考试大纲／考核要求（含目的性质、内容范围、方法形式）
- [ ] **命题计划**（知识点与分值分布、题型比例、难易度分布）
- [ ] **A/B/C 三套试卷**及各自的**标准答案与评分标准**
- [ ] **双向细目表**（知识点×认知层次×分值，与试卷一致）
- [ ] 试卷模板与排版检查记录（B4 横向、36.4×25.7cm、页边距 2.5cm 等，详见 `03_试卷与存档`）
- [ ] 命题审批表、试卷保密与抽取记录
- [ ] 阅卷安排（流水作业分组、复查记录）
- [ ] 阅卷改动签字记录、**成绩变更审批表**
- [ ] 成绩正态性检查与说明
- [ ] 考查课／选修课的综合评定依据材料（平时听课、实验、实习、讨论、作业、测验）

## 提示

- 三套试卷**难易度等同**是硬要求，命制时要对照同一份命题计划与双向细目表。
- 阅卷后的任何改动都要留痕：卷面改动由阅卷人签字，成绩改动必须填《成绩变更审批表》。
