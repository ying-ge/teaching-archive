# 说明 · 试卷与存档

**规定依据**：五、课程评价 → 试卷〔p23–24〕、考试、考核（五）试卷存档〔p23〕

## 规定怎么说

**试卷格式（硬性规定）**

- 试卷一律在 **Word** 文档内编排，必须使用 **B4 纸**打印。纸型：**B4（JIS）、横向、宽度 36.4cm、高度 25.7cm**；页边距：上、下、左、右**各 2.5cm**。
- 试卷内容由**试卷标题、封面、试题及页脚**四部分组成。
- **试卷标题**：首行填写使用本套试卷的年级、专业、课程名称及 A 套、B 套还是 C 套试卷，填写格式为**小三号字、宋体**（模板样式为宋体加粗小三号字）；第二行标明命题的单位，**宋体五号字**；接下来为表格，内容包括考试日期、开闭卷、答卷时间和答题卡类型，**五号字、宋体**。
- **试题部分**：每道大题的上面设有题型和题型说明（宋体加粗五号字）。
  - 大标题前空出两个字符的位置；大题目使用大写数字"一、二、三、四……"（宋体加粗五号字），大标题后括号内的说明文字用宋体五号字。
  - 试题题目前同样空出两个字符的位置；题号使用阿拉伯数字"1、2、3、4……"（宋体五号）。
  - 大标题号和试题的数字后面使用顿号"、"。
  - 选择题选择项格式为 ABCDE，字母的后面一律用"."表示，选项对齐；填空题一律用横线；判断题在题号前打括号。
  - 试题内容用宋体五号字。
- **页脚格式**：第一行"第×页（共×页）"，第二行"（学校全称）试卷纸"，此两行字均为**仿宋体小五号字**。
- 附**试卷评价表**（评价重点：试卷命题、适应程度、试卷评阅、试卷分析；评价等级：优／良／及格／不及格）。

**试卷存档（规定清单）**

1. 双向细目表、学生试卷、标准答案及评分标准。
2. 学生成绩单、成绩分析与考试总结、考场记录单。
3. 实验报告、作业。
4. **试卷至少保存至学生毕业后三年。**
