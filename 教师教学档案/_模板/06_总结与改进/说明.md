# 说明 · 总结与改进

**规定依据**：一、课程准备 → 教案与讲稿（教案使用与管理第 5 条）〔p5〕；五、课程评价 → 考试、考核（四）6、考试总结〔p22–23〕；说课"说评价"的持续改进机制〔p4〕

## 规定怎么说

- 教研室要建立教案档案，**完成教学任务后，及时写出阶段性教学总结，与教案一并交教研室存档**，以备上级检查。
- **考试总结规范，分析科学、客观，并能反馈、指导教学。**
- 考核应有合理的**考试分析与持续改进机制**。
- 考试结束后，教师应进行详细的**试卷分析**，了解学生的学习情况，**及时调整教学方法**。

## 这里放什么

- [ ] 阶段性教学总结（可与教案一并交教研室存档）
- [ ] 课程小结（对应形成性评价第 7 种形式的物化形式之一）
- [ ] 试卷分析报告（原件在 `05_课程评价/03_试卷与存档`，此处可放副本或指向说明）
- [ ] 考试总结
- [ ] 持续改进记录与整改措施落实台账（含上一轮问题的闭环情况）
- [ ] 学生评教、督导反馈及处理情况

## 提示

- 总结要写"下一轮怎么改"，而不是只描述"本轮怎么样"——规定的落脚点是**反馈、指导教学**。
- 建议形成跨轮次的改进台账：每轮遗留问题编号、责任人、完成时间，下一轮开课时逐条复核，避免"年年总结、年年相同"。

## 自查

- [ ] 教学任务完成后已提交阶段性教学总结并与教案一并存档
- [ ] 考试总结已完成且分析科学、客观
- [ ] 改进措施有责任人、有时间表、有闭环记录
