## 一、学期工作时间轴（照此推进即可）

| 阶段 | 时间节点 | 要做的事 | 材料放哪 |
|---|---|---|---|
| ⓪ 开课前 | 立即 | 打印/复制 `00_材料总清点表.md`，按本课程实际勾选"适用范围"，标出 `—` 不适用行 | 课程根目录 |
| ① 上一学期末 | 第 10～12 教学周 | 编制下学期**教材选用计划**，填《教材使用计划表》报分委会审核 | `01_课程准备/02_教学大纲与教材` |
| ② 开课前 | 假期 | 研读大纲、学情分析、编排**教学进度**、备课写教案与讲稿、准备课件与教具 | `01_课程准备/01`～`06` |
| ③ 开课前 | 教研室安排 | 参加**集体备课**（每学期 ≥2 次）；新任课/新开课教师完成**试讲**与**学习性听课** | `01_课程准备/07`～`09` |
| ④ 开课前两周 | 不迟于授课前 14 天 | **教案交教研室主任或指导教师阅批、签字**，否则不准上课 | `01_课程准备/04_教案` |
| ⑤ 开课前一周 | 实验课 | 完成**预实验**（非新开设实验）；新开设实验须在上一个学期完成 | `02_课程教学/02_实验教学` |
| ⑥ 授课周 | 全过程 | 随身携带教案讲稿课件教具；**随时产生的**课堂记录、作业批改、测验卷、小组任务、自主学习记录**当天归档** | `02_课程教学`、`05_课程评价/01` |
| ⑦ 授课周 | 有实验/见习/实习时 | 实验报告批改、见习考勤、教学查房与专题讲座记录、医疗文书批改 | `02`、`03` |
| ⑧ 期末 | 考试前 3～4 周 | 提交**命题计划**、命 A/B/C 三套试卷与标准答案评分标准、双向细目表 | `05_课程评价/02` |
| ⑨ 考后 | 阅卷后 | 网上评卷、流水判题、成绩正态性检查；成绩改动填《成绩变更审批表》 | `05_课程评价/02` |
| ⑩ 考后 | 2～4 周内 | 写**试卷分析报告**与**考试总结**；过程性成绩与终结性成绩合成 | `05_课程评价/03` |
| ⑪ 学期末 | 放假前 | 写**课程小结与持续改进措施**、阶段性教学总结，与教案一并交教研室存档 | `06_总结与改进` |
| ⑫ 存档 | 长期 | 学生试卷等材料**至少保存至学生毕业后三年** | `05_课程评价/03_试卷与存档` |

## 三、命名与归档约定

- 文件名：`日期_内容_版本`，例如 `20250310_第三章教案_v2.docx`、`20250620_内科学A卷.docx`
- 试卷类文件另加课程与套次：`2025-2026-1_内科学_A卷.docx`
- 规定要求**纸质存档**的材料（教案、集体备课形成的基本教案与课件、试卷），电子件放本目录，纸质件按教研室要求存放并在对应 `说明.md` 末尾登记存放位置
- 学生个人信息（成绩单、试卷）按学校数据管理规定保管，不外传
