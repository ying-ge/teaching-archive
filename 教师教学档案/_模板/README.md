## 填写标记

全部表单统一使用三个标记；每个表单开头还注明**本表禁止编造**的具体项。

| 标记 | 含义 |
|---|---|
| **【必填】** | 规定要求记载的项，缺项即材料不合格 |
| **⚠禁止编造** | 只许照抄来源（大纲、教材版权页、课表、成绩单、签到表等），不得估填，也不得由 AI 生成 |
| **【选填】** | 视课程实际情况填写 |

## 归档约定

- 文件名：`日期_内容_版本`，如 `20260910_第3章教案_v2.docx`；试卷类加课程与套次：`2025-2026-1_课程名_A卷.docx`
- 规定要求**纸质存档**的材料（教案、集体备课形成的基本教案与课件、试卷），电子件放本目录，纸质件按教研室要求另行存放
- 学生个人信息（成绩单、试卷）按学校数据管理规定保管，不外传
