# 教学规则对照表

**用途**：一份文件管住全部规定要求。按目录编号分节，开学照「时间轴」推进，平时照「各目录对照」查漏。
**依据**：校级《本科教学质量标准》全文（第一部分 教学过程；页码为完整件页码）。

**编号语义**：

| 编号 | 含义 |
|---|---|
| `0` | **公共资源**（跨课程共用） |
| `1` | **课程直接相关的资源** |
| `2` | **课前需要做的工作** |
| `3` | **课程过程中要做的** |
| `4` | **上完课要做的** |

---

## 一、时间轴（照做即可）

| 时间 | 做什么 | 放哪 |
|---|---|---|
| 每学期**第 10～12 教学周**（前一学期） | 编制下学期教材选用计划，报分委会审核 | `0规定` |
| 开课前 | 参加**集体备课**（每学期 ≥2 次）；新任课／新开课**试讲**；（青年教师）学习性听课 | `2集体备课`、`2试讲与听课` |
| 开课前 | 学情分析、教学大纲、教学进度 | `2学情分析`、`2大纲`、`2教学进度` |
| 开课前 | 写教案、讲稿；准备课件与教具 | `2教案`、`3讲稿`、`3多媒体课件` |
| 开课前 | **说课**（七说＋评议意见） | `2说课` |
| **授课前两周** | 教案交教研室主任阅批、**签字后方可授课** | `2教案` |
| 实验课**教学前一周** | 完成预实验（新开设实验须在**开课前一个学期**） | `2实验准备` |
| 每次课 | 携教案讲稿课件教具；课堂记录、考勤**当天归档** | `3课堂记录` |
| 考试前 3～4 周 | 命题计划、A/B/C 三套卷与答案、双向细目表 | `4终结性评价` |
| 阅卷后 | 成绩正态性检查；改动须签字／填成绩变更审批表 | `4终结性评价` |
| 考后 2～4 周 | 试卷分析报告、考试总结 | `4终结性评价` |
| 学期末 | 阶段性教学总结、课程小结、改进台账 | `4课程总结` |
| 长期 | 试卷等材料**至少保存至学生毕业后三年** | `4终结性评价` |

## 二、各目录对照

### `0` 公共资源

#### `0规定`

- [ ] 教学质量标准全文（已有）
- [ ] 官方模板：教学大纲参考模板、教案参考模板、按认知层级命题
- [ ] **教学任务书**、**教学校历**（`0排课` 已有课程表，这两项缺）
- [ ] 教材使用计划表及审核回执（每学期一次）

#### `0排课`

- [ ] 学期课表、排课信息（已有）
- [ ] 授课时间日程；调课／代课／补课的申请与批复

### `1` 课程直接相关的资源

#### `1教材`

- [ ] 教材版本信息（书名／版次／ISBN／是否国家规划教材）
- [ ] 选用标准自检：凡选必审；优先国家规划教材；马工程教材对应课程必须选用；**学时 ≥32 的选修课**须用公开出版国家规划教材
- [ ] **红线**：授课中另行安排计划外教材 → 按**教学事故**处理

#### `1参考资料`

- [ ] 参考教材／文献／学科前沿资料
- [ ] 参考教案样例、理论课教案、实验课教案（已有）

#### `1实验器材`

- [ ] 器材清单、借用与归还记录
- [ ] 教具清单与借用记录（备课第 12 条要求课前备齐）

#### `1雨课堂培训`

- [ ] 平台操作培训记录、常用指令与提示词

### `2` 课前需要做的工作

#### `2集体备课`

- [ ] 记录表，每学期**≥2 次**；内容更新多或教材改版时增加次数
- [ ] 记录须含：课程名称、参加人员、时间、地点、研讨内容
- [ ] 集体备课后**形成统一的基本教案与课件，并留纸质存档**（统一件属课程资源，可另存 `1参考资料`）
- [ ] 多院共担课程（内/外/妇/儿等）：每年 ≥1 次集中研讨

#### `2试讲与听课`

- [ ] 试讲评议记录：试讲人、参加人员、时间、地点、内容、评价意见、心得或整改措施
- [ ] **试讲内容 ≥4 个标准学时或实际授课时间的 50%**；合格后方可授课；不合格须整改重讲
- [ ] 试讲须准备：教案、讲稿、教学课件、教具
- [ ] 学习性听课：本学科课程全程 ＋ **2～3 门相关学科** ＋ 知名教授理论授课

#### `2学情分析`

- [ ] 学情分析表：学习对象、知识背景、学习能力、思想政治素质
- [ ] 学生知识基础、先修课程学习情况、有利因素与存在问题及对策

#### `2大纲`

- [ ] 教学大纲（现行版，用学校模板）
- [ ] 要点：认知层级统一用**记忆／理解／应用**（不再用掌握/熟悉/了解/自学）
- [ ] 每章填**考核分值**（可写范围如 3-7 分），理论课与实验/见习分表，最后填合计
- [ ] 考核与评价：终结性＋过程性相结合，**至少 3 种**方式并注明占比
- [ ] 保留模板的字体、字号、加粗、行间距；上报版删除红字注解

#### `2教学进度`

- [ ] 教学进度表／**教学日历**（与教学大纲学时一致）
- [ ] 教研室授课时间日程；**授课提醒记录**
- [ ] 进度与教案**同步**

#### `2教案`

- [ ] 教案（纸质＋电子），每次课一份
- [ ] 必须含：一般项目、题目、导入新课、授课内容（目标／课时分配／重点难点关键点／方式方法／教具／步骤）、小结、作业、教材与参考资料
- [ ] 授课内容须注明**应用／理解／记忆**并做特殊标记
- [ ] **授课前两周**送审；**签字后方可授课**；不合格重写
- [ ] **无教案或使用未修改的旧教案者不准上课**
- [ ] 参考官方《教案参考模板（2024年）》：含课程一般信息、20 周授课计划、考核要点／前沿知识／双语教学／自学内容、板书设计、**教学反思与整改**
- [ ] 再次承担同层次同内容任务时须修改教案
- [ ] 青年教师须**同时**有教案与讲稿

#### `2说课`

- [ ] 七说齐备：说课程、说教材、说目标、说学情、说教法、说过程、说评价
- [ ] 评议意见与改进记录
- [ ] 说评价须与考核实际做法一致（形式、比例、持续改进机制）

#### `2实验准备`

- [ ] **实验教学大纲**、实验教学计划、**实验教学日历**、**实验指导提纲**
- [ ] **预实验记录**：新开设实验在开课前一个学期完成；非新开设在实验教学一周前完成；综合性／设计性实验须专家论证并记录
- [ ] 实验分组名单
- [ ] 实验室制度与开放计划
- [ ] 实验教学研讨会记录、综合性／设计性实验开展计划
- [ ] 备注：实验过程记录与考勤归 `3课堂记录`；实验报告批改、考核成绩与及格名单归 `4终结性评价`

### `3` 课程过程中要做的

#### `3多媒体课件`

- [ ] 课件（标注版本）
- [ ] 图表、视频、虚拟仿真等素材
- [ ] 用于对外交流/评比时补：**功能简介**（含版本号、开发者、教研室、主讲教师、职称、联系方式、载体、教学目标含过程性目标、适用范围、教学策略、支撑环境、功能特点、应用建议、参考资料、选用教材）＋**使用说明书**（硬件要求、安装启动、操作、错误处理、输出信息）

#### `3讲稿`

- [ ] 讲稿：授课内容的细化，含教学内容、事例、习题解析、提问、作业
- [ ] **青年教师授课必须同时有教案和讲稿**；高年资教师可只写教案

#### `3课堂记录`

- [ ] 教学过程记录（内容、进度、互动、答疑）
- [ ] 课堂考勤记录
- [ ] 实验过程记录与实验考勤
- [ ] 教学检查／督导听课记录与整改回复
- [ ] 学生反馈意见及处理情况
- [ ] 上课前到教室、关闭手机；**不提前下课、不拖堂**；携带教案讲稿课件教具教材

### `4` 上完课要做的

#### `4形成性评价`

- [ ] 评价方案：**过程性考核占 20%～40%**（由开课院部定）；**每门课 ≥3 种**考核形式
- [ ] 8 类形式的物化材料：
  ① 课堂学习（过程记录、测评卷纸/评价表、反馈意见）
  ② 个人作业（作业纸、**有痕批阅**评语、反馈意见）
  ③ 团队作业（过程记录、小组小结、教师评价）
  ④ 阶段性测验（卷纸/评价表、反馈意见）
  ⑤ 实践学习（教案、过程记录、实验/实践报告）
  ⑥ 自主学习（学生作业、视频观看记录、教师评价）
  ⑦ 期末考试材料（双向细目表、试卷、综述、分析报告、课程小结）
  ⑧ 其他形式
- [ ] **自评＋互评＋教师评价**三结合；自评互评必须与教师评价结合
- [ ] 成绩合成表（过程性＋终结性）

#### `4终结性评价`

- [ ] 考试大纲／考核要求（目的性质、内容范围、方法形式）
- [ ] 命题计划；**双向细目表**（分值合计＝命题计划＝试卷实际分值）
- [ ] **A、B、C 三套试卷**（难易度等同）＋ 每套**标准答案与评分标准**（采分点明确）
- [ ] 比例红线：主客观 **6:4**；难中易 **1:3:1**；双语课程英文命题 **≥50%**
- [ ] 与教学大纲**考核分值**交叉核对（各章分值合计＝试卷分值）
- [ ] 阅卷：网上评卷、**多人流水作业**、复查；每小题有得分标记
- [ ] 试卷改动须阅卷人签字；成绩改动须填**成绩变更审批表**
- [ ] 成绩呈**正态分布**
- [ ] 实验报告及批改记录、**实验课考核成绩与及格名单**（不及格者不得参加理论考试）
- [ ] 试卷分析报告、考试总结、考场记录单
- [ ] 存档：双向细目表、学生试卷、标准答案、成绩单、分析总结、考场记录单、**实验报告与作业** → **保存至学生毕业后三年**

#### `4课程总结`

- [ ] 阶段性教学总结（完成教学任务后及时写，**与教案一并交教研室存档**）
- [ ] 课程小结；考试总结
- [ ] 持续改进台账（问题、措施、责任人、完成时间、闭环）

## 三、一页清点（学期末自查）

- [ ] 教学任务书、教学日历、课程表齐全
- [ ] 教材选用计划已报批，未使用计划外教材
- [ ] 集体备课 ≥2 次，统一教案课件已纸质存档
- [ ] （如适用）试讲合格、学习性听课记录齐全
- [ ] 学情分析、教学大纲、教学进度表完成，进度与教案同步
- [ ] 教案（纸质＋电子）齐全，开课前两周已签字
- [ ] 青年教师讲稿齐全；高年资教案已按本轮修改
- [ ] 说课七说＋评议意见
- [ ] 实验课：实验大纲/计划/日历、指导提纲、预实验记录、**考核及格名单**、实验室制度与开放记录
- [ ] 形成性评价 ≥3 种，过程性占比符合院部规定，物化材料齐全
- [ ] A/B/C 三套卷＋答案＋双向细目表＋大纲分值核对；主客观 6:4、难中易 1:3:1
- [ ] 试卷分析报告、考试总结、课程小结、改进台账
- [ ] 试卷等材料保存至毕业后三年

## 四、说明

1. 页码依据完整件（103 页，含第一～四部分）；本表覆盖**第一部分 教学过程**。第二～四部分（教学管理／教学条件／质量保障）中的教学检查、授课质量评价、试卷评阅与成绩管理另有要求，需要时再补。
2. 编号语义：`0` 公共资源／`1` 课程直接相关资源／`2` 课前要做的工作／`3` 课程过程中要做的／`4` 上完课要做的。同一编号可重复（同阶段的多类材料）。
3. 分类原则：**资源**看"是什么东西"（教材、器材、参考资料）；**工作**看"什么时候做"（课前／课中／课后）。因此集体备课、试讲、听课记录属 `2`（课前工作），而不是 `1`（资源）。
4. 非临床课程不需要临床见习／实习／技能培训目录。
5. 现有两处嵌套（`1参考资料/实验课教案`、`1参考资料/理论课教案`）—— 如要统一为单层，可改为 `1理论课教案`、`1实验课教案` 两个顶层目录。
6. 若将来教第二门课，建议在课程特有目录下加一层课程名（如 `2大纲/普通生物学/`），`0` 类公共资源留在顶层。
