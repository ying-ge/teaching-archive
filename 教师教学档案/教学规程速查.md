## 一、课程准备

### 1 备课 〔p1–2〕

**个人备课（12 条要求）**

- [ ] 了解本门课程在专业教学计划中的地位与任务，理清与相关学科课程、先修/后续课程的联系
- [ ] 学习并领会学校各项规章制度、教学相关文件
- [ ] 掌握教学大纲与教学基本要求，分清主次与逻辑结构，准确把握"三基"（基础理论、基本知识、基本技能）、"三性"（科学性、系统性、实践性）、"三点"（重点、难点、疑点）
- [ ] 做好**学情分析**：调查学生学习基础、知识结构、先修课程学习情况
- [ ] 钻研教材，并广泛收集阅读参考资料、了解学科最新进展
- [ ] 选择科学的教学方法，合理使用现代化教育手段，开展研究型学习，编写案例，开展 PBL 教学
- [ ] 授课内容体现**高阶性、创新性、挑战度**
- [ ] 承担实验授课的教师还须掌握实验全部内容、仪器设备基本原理并熟练操作、做好**预实验**
- [ ] 按规定要求合理编排**教学进度**，认真书写**教案和讲稿**
- [ ] 课前准备好图表、教具、电子课件、作业习题；必要时进行预讲和演练

**集体备课**

- [ ] 教研室每学期集体备课**不少于 2 次**；教学内容更新较多或教材改版时**增加次数**
- [ ] 多所临床学院（含非直属医院、教学医院）共同承担的课程（内科学、外科学、妇产科学、儿科学等），其临床教研室**每年至少 1 次**集中教学研讨会或集体备课
- [ ] 由教研室主任（副主任）或课程负责人主持，教研室全体人员参加，可邀请相关学科专家、教学督导
- [ ] **记录必备要素**：课程名称、参加人员、时间、地点、研讨内容
- [ ] 集体备课后须形成**统一的、符合教学大纲的基本教案和教学课件，并留纸质存档**；教师据此完善个人教案与课件

### 2 试讲 〔p2–3〕

- [ ] **适用范围**：新任课教师、新开课程、经专家或学生教学评价不合格的教师 → 必须试讲和评议
- [ ] 试讲**合格后方可正式授课**；不合格须整改并重新试讲
- [ ] **学习性听课**：青年教师或新转岗入职教师上课前须先学习性听课——全程听本学科课程、**2～3 门相关学科课程**、知名教授的理论授课；必要时与本科生一起参加考核
- [ ] 老中青教师之间、基础与临床课程教师之间相互听课，扩展专业知识、相互学习教学方法
- [ ] 试讲由教研室主任（副主任）主持，教研室全体人员参加
- [ ] 试讲教师须准备**教案、讲稿、教学课件和教具**
- [ ] **试讲内容不少于 4 个标准学时，或实际授课时间的 50%**
- [ ] **记录必备要素**：课程名称、试讲人员、参加人员、时间、地点、试讲内容、评价意见、试讲者心得或整改措施
- [ ] 试讲不合格者，教研室指定专人指导帮扶并重新组织试讲

### 3 说课 〔p3–4〕

- [ ] **说课程**：课程在专业人才培养中的作用
- [ ] **说教材**：本节内容在教材中的地位作用、依据大纲对教材的分析与思考
- [ ] **说目标**：教学目标具体明确、学时分布合理、重难点契合教材与学生实际
- [ ] **说学情**：知识基础、学习态度、学习方法、有利因素、存在问题及对策与学法指导
- [ ] **说教法**：选择依据、创新性，恰当运用图片/视频/动画/音频/虚拟仿真等素材
- [ ] **说过程**：各环节知识点选取恰当、串联合理；体现创新性与前沿性，及时引入学术前沿成果；强调高阶性与以学生为中心
- [ ] **说评价**：考核要求与课程目标对应；过程性考核要求明确，开展形成性评价；多元考核＝形成性＋终结性；有考试分析与**持续改进机制**

### 4 教案与讲稿 〔p4–5〕

**教案基本格式（7 项）**

- [ ] 一般项目：学科和课程名称、授课对象（专业、年级、班级）、任课教师
- [ ] 题目
- [ ] 导入新课
- [ ] 授课内容：教学目标与要求、教学内容及课时分配、授课重点/难点/关键点、授课方式、教学方法、教具、教学步骤
- [ ] 小结
- [ ] 布置作业
- [ ] 教材和参考资料

**编写要求**

- [ ] 明确教学目的（专业人才培养目标 ＋ 知识传授 ＋ 技能培养 ＋ 素质培养 ＋ 思想政治教育 五项）
- [ ] 钻研大纲、钻研教材，确定重点、难点、关键点
- [ ] 了解学生（知识、能力、素质），因材施教
- [ ] 书写字迹工整清晰，注重思想性、科学性、逻辑性、艺术性
- [ ] 按授课篇、章、节、题目、目的要求、教学方法、教学内容、小结等顺序编写；**授课内容必须注明"应用/理解/记忆"内容并做特殊标记**
- [ ] 同时具备**纸质教案和电子教案**

**使用与管理（红线）**

- [ ] 课堂讲授和实验实习课教学**均要编写教案**；授课时**随身携带教案**
- [ ] **授课前两周**将教案交教研室主任或指导教师阅批；**合格并由教研室主任签字后方可授课**；不合格必须重写
- [ ] **无教案或使用未修改的旧教案者不准上课**
- [ ] 再次承担相同层次、相同内容的教学任务时，须认真修改教案、增减内容
- [ ] 教案与教学进程同步
- [ ] 教研室建立**教案档案**；完成教学任务后及时写出**阶段性教学总结**，与教案一并交教研室存档
- [ ] 各院、系、部随时检查教师教案，学校不定期抽查，对无教案或教案不合格者予以处理
- [ ] **青年教师**授课时必须同时书写教案和讲稿；高年资教师在保证授课质量前提下可只写教案

### 5 教材 〔p5–6〕

- [ ] **凡选必审**；坚持质量第一、适宜教学、公平公正、统一使用原则
- [ ] 优先选用国家规划教材及获省部级以上奖励的优秀教材；马工程重点教材对应课程必须选用马工程重点教材
- [ ] 不得选用政治立场和价值导向有问题、内容陈旧、低水平重复、简单拼凑的教材
- [ ] 选用标准兼顾思想性、科学先进性、适用启发性、电子教材专门标准
- [ ] 必修课和**学时 ≥32 学时**的选修课原则上选用公开出版的国家规划教材；自编教材未经学校审批不得列入选用计划
- [ ] 同一教学大纲的课程原则上选用同一版本教材；因改革、试点、分层次教学需更换版本须报教材建设办公室批准
- [ ] 教材选用一定时期内保持相对稳定；评价不合格的教材必须更换
- [ ] **授课中另行安排计划外教材，一经查实按教学事故处理**
- [ ] 使用外国教材须为原版或已授权的国内版，并报主管部门批准
- [ ] **选用程序**：每学期编制一次；一般在前一学期**第 10～12 教学周**制定下一学期教材选用计划；教研室填报《教材使用计划表》→ 教学单位教材建设分委会审核 → 学校教材建设委员会办公室审核备案
- [ ] 更换新版本教材须提供新教材样书或编写大纲，按程序审批

## 二、课程教学

### 6 理论教学 〔p6–8〕

**质量保障（可核查动作）**

- [ ] 在规定上课时间**之前**进入教室，熟悉环境、调配教具与教学辅助设备，**关闭手机等通讯设备**
- [ ] 上课时携带**合格的教案、讲稿、电子课件、教具以及教材**等必要材料
- [ ] 准时上课，**不提前下课，也不延长时间**
- [ ] 认真组织课堂教学，保持教学秩序良好
- [ ] 教研室合理安排任课教师，制定合理、正确的授课时间日程
- [ ] 建立**授课提醒制度**

**评价标准 5 个维度**：教学态度／教学能力／教学内容／教学方法／教学效果。要点：备课准备充分、教案规范、遵守时间；精通专业内容、语言准确精练、讲授有系统性、合理运用课堂时间；概念讲解清楚准确、重点突出、理论联系实际、**按既定教案授课**、禁止"照本宣科"、注重课程思政；启发式/案例式/PBL 教学、合理运用现代化信息技术、板书清晰；及时总结归纳、激发学习兴趣、达到教学互动、因材施教。

### 7 实验教学 〔p8–10〕

- [ ] 实验课必须有**实验教学大纲**（组织实验教学的指导性文件）
- [ ] 制定**实验教学计划、实验教学日历**，编写**实验指导提纲**，备好仪器、设备、试剂、动物等
- [ ] **预实验**：新开设的实验内容，教研室必须在**开课之前的一个学期**完成预实验；综合性、设计性实验必须邀请相关专家**论证并做好记录**；非新开设的实验内容应在**实验教学一周以前**完成预实验
- [ ] 针对不同专业、不同层次对实验项目、内容进行删减重组（因需施教）
- [ ] 教研室定期召开实验教学研讨会，大力开展综合性、设计性实验并扩大比例
- [ ] 建立健全实验室制度，建立**实验室档案**；完善实验室开放制度
- [ ] 课前组织学生检查仪器设备、试剂是否齐全；课后清点用品、做好卫生与仪器保养
- [ ] 严格上下课时间与课堂纪律，**严格考勤并记录**
- [ ] 课后**认真批改实验报告**，实验报告成绩可作为实验成绩的一部分
- [ ] 实验课成绩占该课程总成绩的一定比例；**实验课考核及格者方可参加该门课程理论考试**

## 三、实践教学

### 8 临床见习 〔p10–11〕

原文由 8 个方面标准组成：教学大纲标准（见习部分）、教学大纲执行标准、教学准备标准、教学实施标准、教学内容标准、教学方法标准、教学态度标准、教学效果标准。

- [ ] 掌握大纲教学内容与要求，**经过集体备课和试听、试讲**
- [ ] 课前预先准备和熟悉**教学病例**，备好教学提纲、教案、讲稿以及影像图片、心电图等有关教学资料
- [ ] 特殊或传染性疾病教学课前**做好师生的防护措施**
- [ ] 见习课前进行**考勤记录**，检查学生着装及学习用品
- [ ] 对病人临床材料进行综合分析，病情诊断、处置和治疗方案正确、依据充分；关心病人、医患关系融洽，体现医德示范
- [ ] 教学组织严密科学，遵守医疗和教学规范
- [ ] 教学内容概念清楚、系统完整、重点突出、深度广度适宜；根据科室病种情况灵活掌握见习内容与安排
- [ ] 教学方法体现启发式、病案式、PBL，贯彻"三基""三严"，采用示教、讲解、讲座、讨论等多种方式
- [ ] 达到对学生的临床思维和临床处理问题能力的培养要求

### 9 临床实习 〔p11–17〕

原文由 10 个方面标准组成：实习文件标准、教学基地标准、实习准备标准、实习带教标准、教学查房标准、专题讲座标准、实习考核标准、医疗文书书写标准、实习管理标准、二级学院对教学基地教学查房（教学指导）标准。

**实习文件与准备**

- [ ] 实习计划、实习大纲、实习手册、实习考核表齐全，执行严格，由教务处组织临床教学专家编写并定期修订
- [ ] 教务处根据教学进程**提前两个月**下达各专业实习计划任务
- [ ] 二级学院落实实习分组、地点、轮转安排并上报教务处；实习前将实习计划、安排、名单送达教学基地
- [ ] 按时向教学基地和学生发放实习大纲、实习手册等文件
- [ ] 实习前对带教教师开展教学培训；对学生开展**实习动员**（安全培训、规章制度、学习方法、医德培养等）
- [ ] 教学基地在实习开始前整理研究实习文件，学生进入基地后组织**入院前培训**

**实习管理（量化指标）**

- [ ] 每个科室设置 **2 张以上教学专用床**用于调节病种
- [ ] 每名实习学生负责管理 **6～8 张病床**为宜
- [ ] 指导教师原则上由**高年资住院医师及以上**者担任，**不允许进修医师担任**
- [ ] 每名指导教师负责指导 **1～2 名学生**
- [ ] 严格按照实习计划和实习轮转表组织实习安排，完成学生全部实习内容

**教学查房、专题讲座**

- [ ] 执行《教学查房规范（试行）》
- [ ] 教研室教学查房**每周至少 1 次**，要有**计划、实施、记录和总结**
- [ ] 专题讲座**每 1～2 周安排一次**；各教研室制定学期专题讲座计划，安排高年资教师承担；时间、题目、主讲人**一旦确定不得随意更改**；内容结合临床实践并充实前沿理论与学科发展
- [ ] 二级学院对教学基地教学查房：每学期**有计划、有实施、有记录、有总结**；查房教师须具**副教授以上**职称

**实习考核**

- [ ] 百分制记分，两种方式择一：①平时考核 70 分＋出科理论考试 30 分；②平时考核 40 分＋出科技能考核 30 分＋出科理论考试 30 分
- [ ] 平时考核由带教教师评定、教研室审定，内容包括劳动纪律、服务态度、遵守制度、工作表现、文书书写、体格检查、基本操作等
- [ ] 出科技能考核以**面试形式**（床前或临床技能训练设备、模拟病人等）考核本科室基本工作技能和临床实践知识
- [ ] 出科理论考试以**笔答形式**考核本科室教学内容，重点考核理论联系实际的应用能力和临床思维
- [ ] 试卷由各学院组织教研室统一命题，每轮出科考试前**保密下发**各教学基地，**统一时间**组织出科考试
- [ ] 考核成绩使用**蓝、黑墨水**填写，不得污损及涂改
- [ ] 成绩评定表、实习成绩表须**考评教师及教研室主任签字**；上报二级学院及学校的成绩登记单须**教学基地教学管理部门盖章**
- [ ] 二级学院、教学基地对实习成绩进行科学客观分析，做出规范的考试总结

**医疗文书书写**

- [ ] 医疗文书包括病历、病程记录、查房记录、转科记录、会诊记录、手术记录、出院记录、死亡记录、医嘱与处方、检查单等
- [ ] 病史采集真实、完整、系统；使用规定颜色笔书写，字迹清楚规整；规范使用医学术语，不得自行杜撰简化或缩写
- [ ] **带教教师必须对学生的各种医疗文书进行审查、修改和补充并签名；每页修改超过两处必须重新抄写**
- [ ] 学生须在带教教师指导下书写、确认，不得弄虚作假

### 10 临床技能培训 〔p17–19〕

- [ ] 指导材料以教学大纲和实习大纲为准绳，兼顾临床实际情况与执业医师考试内容，体现"三基""三严"
- [ ] 考核标准明确、标准、规范，具有可操作性
- [ ] 基本原则：**严格、规范、熟练、准确、细致**
- [ ] 培训内容覆盖**"阅、查、说、写、思、技"**六方面临床技能
- [ ] 培训以基本项目为主（内科/神经内科/儿科、外科、妇产科各系列操作项目），**原则上不能漏项**，并在**实习手册中如实记录**
- [ ] 形式：集中讲解、分别指导训练；指导教师特别注意学生手法的正确与轻柔
- [ ] 途径：带教老师带领下的临床医疗实践训练 ＋ 临床技能训练实验室模拟训练 ＋ 出科技能考核巩固提高
- [ ] 培训保持系统性和连续性，贯穿学生学习全过程
- [ ] 临床学院加强对所属教学医院技能培训的指导、检查，保证培训和考核标准统一

## 四、教学手段

### 11 多媒体教学 〔p19–20〕

- [ ] 课件教学目标明确，符合课程教学大纲要求，适应教学和学习对象需要
- [ ] 教学内容取材合适、重点突出、科学准确、深入浅出，例题典型、练习分量恰当，注重启发式教学与创新能力培养
- [ ] 教学过程所采用的教学方法符合学生认知规律，具有启发性
- [ ] 课程总体设计科学，能反映国内外先进的科学研究和教学研究成果，教学交互设计合理，有创新性
- [ ] 授课教师能熟练掌握多媒体操作技术，无操作失误
- [ ] 课件正常条件下运行稳定；组织结构与呈现方式适合教学需要；界面友好、布局合理、色彩协调、美观大方
- [ ] 具有内容调整、组合、更新、补充的开放性和可扩展性功能
- [ ] **文档资料完整**：课件文档资料包括**功能简介**和**使用说明书**两部分
- [ ] 功能简介应含：课件名称及版本号、开发者姓名、教研室、主讲教师姓名、职称、联系方式、课件载体、教学目标（含过程性目标）、适用范围及对象、教学策略、课件支撑环境要求、功能特点、应用建议、参考资料、选用教材
- [ ] 使用说明书应含：硬件支撑环境要求、安装启动方法、操作、错误处理说明、输出信息等
- [ ] 有显著特色与创新，可显著提高教学效率、受益面广
- [ ] 学校于每学期开学前开展**两次**多媒体设备操作专题培训；学校、学院（系）、教研室定期检查、评比

## 五、课程评价

### 12 形成性评价 〔p20–22〕

**8 种评价形式（括号内为规定的"物化形式"）**

- [ ] ① **课堂学习**（教学过程记录、测评卷纸或评价表、反馈意见）
- [ ] ② **个人作业**（作业纸/文档、批阅评语、反馈意见）—— 须**有痕批阅**，形式可含小论文、研究报告等综合性作业
- [ ] ③ **团队作业**（过程记录、学生学习小结、教师评价反馈）—— 小组总成绩＋成员依贡献自评
- [ ] ④ **阶段性学习测验**（测评卷纸或评价表、反馈意见）—— 单元结束后开展，可采取期中考试、单元测验
- [ ] ⑤ **实践学习**（教案、教学过程记录、实验报告、实践报告、反馈意见）
- [ ] ⑥ **自主学习**（学生作业、学生视频观看记录、教师评价）
- [ ] ⑦ **期末考试**（双向细目表、试卷、综述、试卷分析报告、课程小结）
- [ ] ⑧ **其他形式**：教师根据课程特点自行设计

**评价要求**

- [ ] 建立以过程性考核为主的平时成绩评价制度；最终成绩＝过程性考核成绩 ＋ 终结性考核（期末成绩）
- [ ] **过程性考核成绩建议占课程总成绩的 20%～40%**，具体比例由开课院（部）确定
- [ ] **建议每门课程采取三种以上考核评价**
- [ ] 形成性评价遵循**过程性、互动性、个性化、持续性**原则，及时反馈学生并调整教学方案
- [ ] 评价主体多元化：**自我评价＋群体互评＋教师评价**三者有机结合；学生自评与互评**必须与教师评价结合**
- [ ] 教师评价应具体和有针对性，包括优点和缺点，可用日常记录或学生行为评价表

### 13 考试、考核 〔p22–23〕

- [ ] 每门课程应有**考试大纲或考核要求**，内容包括：考试的目的和性质、考试的内容和范围、考试的方法和形式（题型、题目数量、各部分内容所占分数比例、答卷方式等）
- [ ] 考试课和须闭卷考核的考查课均须命出**难易度等同的 A、B、C 三套试卷**，同时做出**标准答案与评分标准**；由教务处随机抽取一套用于正常考试，另两套封存备补考
- [ ] **主客观试题比例约为 6:4；难、中、易比例控制在 1:3:1**
- [ ] 双语教学课程用英文命题所占比例**不低于 50%**
- [ ] 试卷必须采用**统一的试卷模板**；原则上所有考试课科目须作出**命题计划**，从题库命题、组卷
- [ ] 标准答案和评分标准科学、采分点明确，能严格执行；**成绩呈正态分布**
- [ ] 考查课、选修课由二级学院及教研室针对课程特点综合评定，**不能降低标准，保存好相关材料以备检查**
- [ ] 考试课实行**网上评卷**；试卷多人流水作业判题，组织好试卷复查
- [ ] 卷面批阅形式统一、规范、整洁、美观；认真填写试卷封面各项内容；**每小题需有得分标记**
- [ ] 试卷批阅如有改动**必须有阅卷人签字**；成绩疏漏需改动**必须填写成绩变更审批表**后方可生效
- [ ] 考试总结规范，分析科学客观，能反馈、指导教学

**试卷存档（保管期限）**

- [ ] 双向细目表、学生试卷、标准答案及评分标准
- [ ] 学生成绩单、成绩分析与考试总结、考场记录单
- [ ] 实验报告、作业
- [ ] **试卷至少保存至学生毕业后三年**

### 14 试卷 〔p23–24〕

- [ ] 试卷一律在 **Word** 文档内编排，使用 **B4（JIS）纸、横向、宽 36.4cm、高 25.7cm，页边距上下左右各 2.5cm**
- [ ] 试卷内容由**试卷标题、封面、试题及页脚**四部分组成
- [ ] 标题首行：年级、专业、课程名称及 A/B/C 套试卷，**小三号字、宋体加粗**；第二行命题单位，宋体五号；随后为考试日期、开闭卷、答卷时间、答题卡类型的表格（五号宋体）
- [ ] 每道大题上方设题型和题型说明（宋体加粗五号）；大题用"一、二、三……"；小题用阿拉伯数字"1、2、3……"；大标题号和试题数字后使用顿号"、"
- [ ] 选择题选项格式 ABCDE，字母后一律用"."，选项对齐；填空题一律用横线；判断题在题号前打括号；大标题前、题目前均空出两个字符位置
- [ ] 页脚第一行"第×页（共×页）"，第二行"（学校全称）试卷纸"，均为仿宋小五号
- [ ] 使用**试卷评价表**（评价重点：试卷命题、适应程度、试卷评阅、试卷分析；等级：优/良/及格/不及格）
